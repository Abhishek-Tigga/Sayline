18 cases · the bar for pass is one question only: would you press send without editing a single word? Not "is it good" — would you ship it as-is. If you'd touch it, it's a fail, and the tags say why.

Protocol: chord-dictate each script into the named room (or a stand-in text field), speaking naturally — the script is a prompt, not scripture; your own ums and detours make the test better. Paste what landed, mark it, tag fails, add a remark where the tags don't cover it. Marks save in this browser only, which is how round 1's answers were lost. Export downloads a file — do it partway through, not just at the end. Send the file to Fable.
Check the facts, not just the tone. The guard was made more permissive on 2026-08-14 — six rules relaxed, none tightened. So for every case, verify each number, name, day and time against what you actually said, and tag fact wrong if any drifted. That is the half the machine is now weakest at, and a wrong number is invisible in a sentence that reads well.

One hole the guard cannot cover. If a sentence keeps any negative word, the guard will not notice a different position being flipped. So "I don't agree with the plan" arriving as "I agree with the plan" can pass silently. Read every position — a no must still be a no.
The bar for this round (Fable, 2026-08-14). Two absolutes: zero invented facts and zero silent fallbacks — every time you got your own words back, you should have seen a notice saying so. Then send-unedited: under 30% means the prompt approach gets re-examined, 30–60% means iterate, 60%+ means taste work steps back and the launch work takes priority.
