Work mode — live test sheet

Hold the chord for work mode on every case unless the row says otherwise. Judge what lands in the text field, not what the log says happened.

These tests are written to try to break what was built.
  • Every case names the assumption it is attacking. If a test passes, that assumption survived a real attempt on it — which is worth more than a test written to agree.
  • C1 is marked expect fail. It is known-broken and unfixed, recorded in the ledger as OPEN FOR FABLE. It is here so the sheet cannot look clean by leaving it out — a test suite that omits the known failure is a rubber stamp.
  • Sections C and D matter most. C hunts for things the guard lets through; D hunts for good rewrites it blocks. Both are harder to see than a guard doing its job, and both are where the design is most likely wrong.
  • Where a case expects an exact sentence, being close is a fail. Write what actually appeared in the remarks — the wording is the evidence.
